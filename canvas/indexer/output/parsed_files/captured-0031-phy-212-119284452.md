## Problem 1

Set angular velocity to zero when it reverses direction:

0 = A - B t^2

t = sqrt(A / B) = sqrt(18 / 0.50) = sqrt(36) = 6.0

Answer: 6.0

## Problem 2

The disk reverses at t = 6.0 s.

Angular displacement:

Delta theta = integral from 0 to 6 of (A - B t^2) dt

Delta theta = A t - (B / 3) t^3

Delta theta = 18(6.0) - (0.50 / 3)(6.0)^3

Delta theta = 108 - 36 = 72

Answer: 72
