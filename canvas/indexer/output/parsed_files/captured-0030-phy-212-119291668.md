## Problem 3

Average angular speed:

omega_avg = (omega_I + omega_F) / 2 = (12 + 0) / 2 = 6 rad/s

Angular displacement:

Delta theta = omega_avg t = (6)(26) = 156 rad

Convert to revolutions:

156 rad (1 rev / 2 pi rad) = 24.83 rev

Answer: 25 revolutions
