Action 1: When I see that symbolic notation the first thing that comes to mind is the Riemann sum notation. This is the type of notation that needs to be used when there are too many rectangles to write each one out by hand to estimate the area under the curve. As the number of rectangles increases the answer becomes more accurate.

 

Action 2: For image 1, that symbol notation wants all the separate areas of the rectangles to be added up from the first rectangle to the nth rectangle. Graphically it means to added up all the rectangles under the curve to estimate the total area. For image 2, it represents the heights of each rectangle on the graph. The height is determined by the function value that is chosen based on the type of interval you are using (left endpoint, midpoint, or right endpoint). For image 3, it represents the width of each rectangle. Graphically it represents each subintervals width. As delta x gets smaller, more rectangles are created and gives a more accurate approximation of the area under the curve.
