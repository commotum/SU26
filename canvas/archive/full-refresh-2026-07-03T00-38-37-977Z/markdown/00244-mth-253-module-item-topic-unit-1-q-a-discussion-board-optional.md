Fundamental Limits.

Did you know that some of the indeterminate limits should not be computed by l'Hôpital theorem, even it looks like it can be applied formally? Some of these limits are sometimes called the fundamental limits.

Introduction: the case of \(\sin x/x\).

One such fundamental limit is

\(\lim\limits_{x\to 0}\dfrac{\sin\, x}{x}\,.\)

Note that formally l'Hôpital theorem seems applicable: it is \(\frac{0}{0}\) indeterminate and we can write that

\(\lim\limits_{x\to 0}\dfrac{(\sin\, x)'}{(x)'}=\lim\limits_{x\to 0}\dfrac{\cos\, x}{1}=\dfrac{1}{1}=1\,,\)

so we could conclude that

\(\lim\limits_{x\to 0}\dfrac{\sin\, x}{x}=1\,,\)

which is in fact the case!

So what is the problem?

The problem is that we cannot prove that \((\sin x)'=\cos x\) without first proving that  \(\lim\limits_{x\to 0}\dfrac{\sin\, x}{x}=1\)!

That is, if we claim that this limit is 1 by l'Hôpital theorem, then we need to know that the derivative of sine is the cosine, but to know that derivative of sine is cosine we need to know that this limit is 1 in the first place! So, to avoid a circular reasoning, we need to find a way to prove that

\(\lim\limits_{x\to 0}\dfrac{\sin\, x}{x}=1\)

by a method independent on l'Hôpital. Typically, this is done using a squeeze theorem by estimating \(\sin x\) from above and from below using the triangles. 

Here is a short video showing how one uses the fact that \(\lim\limits_{x\to 0}\dfrac{\sin\, x}{x}=1\) to show that \((\sin x)'=\cos x\) from Khan Academy: https://www.youtube.com/watch?v=HVvCbnrUxek
Links to an external site.

This is a more detailed video that also explains how to show that \(\lim\limits_{x\to 0}\dfrac{\sin\, x}{x}=1\) from MIT: https://www.youtube.com/watch?v=FtQl1gAo12E
Links to an external site.

Other fundamental limits

Some of the other important fundamental limits are: 

\(\lim\limits_{x \to 0} \dfrac{\cos x - 1}{x} = 0\)

\(\lim\limits_{x \to \infty} \left( 1 + \dfrac{1}{x} \right)^x = e\)

\(\lim\limits_{x \to 0} \dfrac{\ln (x + 1)}{x} = 1\)

If you are interested, there is plenty of stuff you can find on the web about these limits!

Another interesting (albeit a non-fundamental) limit where l'Hôpital fails is

\(\lim\limits_{x \to \infty}  \dfrac{x}{\sqrt{x^2+1}} = 1\,.\)

Try to see why!
