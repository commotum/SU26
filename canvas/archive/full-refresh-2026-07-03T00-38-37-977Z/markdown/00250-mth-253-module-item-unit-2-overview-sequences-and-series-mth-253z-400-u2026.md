Unit 2 - Overview

Introduction

In this unit we will learn about sequences and series. What specifically is a sequence, and what do we need to know about them? What is a series, and how does it differ from a sequence? This unit will answer each of these questions!

Unit Learning Outcomes

After successful completion of this week, you will be able to:

Construct formulas that generate explicitly defined sequences. 
Determine the limiting behavior of some simple recursively defined sequences (function iteration). 
Evaluate if a sequence converges or diverges. 
Assess if a series is convergent or divergent from the partial sums.
Evaluate the convergence or divergence of geometric and telescoping series.
