Module 2 — Overview

Introduction

This week we will make connections between Riemann sums and the definite integral, highlighting the difference between approximation versus exact.  Application problems using both tools will be considered.  Finally, we will introduce the Fundamental Theorems of Calculus, which will be an important springboard for future weeks.  

Module Learning Outcomes

After successful completion of this module, you will be able to:

Evaluate finite Riemann sums using the course Riemann sum Calculator (RSC).
Make connections between the value of a Riemann sum and an associated application problem.
Relate and convert between Riemann sums and definite integrals.
Determine the error for a left, right, or midpoint approximation (Riemann sum) for a given number of rectangles.
Use geometry to find the area under special types of curves.
