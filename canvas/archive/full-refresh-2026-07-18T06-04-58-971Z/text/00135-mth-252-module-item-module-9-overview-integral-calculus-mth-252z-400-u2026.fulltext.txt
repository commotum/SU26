Introduction
We now transition from solving graphical application problems to solving real-world application problems using techniques of integration.  Although all graphical applications do have real-world applications, the topics we turn to are clearly related to physical phenomena: Mass, Force, and Work. Notice that in the previous material, the regions related to the graphs were the application problems. In these real-world problems, the graphs are indirectly highlighting a component of the physical problem.
Module Learning Outcomes
After successful completion of this module, you will be able to: 

Compute the mass of an object using linear and radial density functions.
Apply Hooke’s law to set up and evaluate problems involving springs.
Determine the force function for a spring in equilibrium.
Determine the work needed to push/pull a spring a specified distance.
Determine the work needed to pump a fluid vertically a specified distance.
Find the (hydrostatic) force on a given surface submerged in a fluid.

This module aligns with the following course learning outcomes: 3, 4.
