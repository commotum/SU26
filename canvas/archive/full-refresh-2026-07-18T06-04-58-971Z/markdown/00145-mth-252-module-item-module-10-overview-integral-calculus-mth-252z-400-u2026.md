Module 10 - Overview

Introduction

We complete our study of real-world applications of integration by exploring integrals covering an infinite region.  Integrals of graphs that “go to infinity” are called Improper Integrals.  These have various real-world applications in physics, probability theory, statistics, differential equation, etc. 

Module Learning Outcomes

After successful completion of this module, you will be able to:

 

Evaluate improper integrals with an infinite limit(s) of integration.
Evaluate improper integrals with an unbounded integrand.
Solve application problems using improper integrals.

This module aligns with the following course learning outcomes: 3, 4.
