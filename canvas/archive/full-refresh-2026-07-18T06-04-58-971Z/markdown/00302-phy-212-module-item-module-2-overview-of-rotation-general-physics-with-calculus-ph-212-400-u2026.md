Module 2 | Overview of Rotation

 

Introduction

For this module, we will focus on aspects of rotation of an object or a system of objects.

Weekly Learning Outcomes

After successful completion of this week, you will be able to: 

define center of mass in general
find the center of mass for a specific object or system
calculate the rotational energy of an object or a system
define moment of inertia in general
find the moment of inertia for a specific object or system
define torque
calculate the torque for a specific object or system
Specify attributes for a system in static equilibrium
construct an extended free-body diagram
analyze a system including net force and net torque equations
describe properties of a rolling object
define angular momentum
determine if angular momentum is conserved in a system
analyze a system using an angular momentum conservation approach
