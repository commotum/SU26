## Problem 1

Select every true statement about the substitution method.

- It can only be used to evaluate definite integrals.
- It uses the identity $\displaystyle \int f(u(x))u'(x)\,dx=\int f(u)\,du$.
- It is based on the power rule for derivatives.
- It is useful for evaluating $\displaystyle \int 3x^2\sqrt{x^3+2}\,dx$.
- It is based on the chain rule for derivatives.

$$
\int\frac{2x+9}{(3x^2+27x-3)^4}\,dx
